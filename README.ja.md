# sampleman

DTM（デスクトップミュージック）制作のためのクロスプラットフォームなサンプル/オーディオライブラリマネージャー。

> **概要** — sampleman は、WAV/MP3/FLAC/MIDI のループやワンショットを大量に扱うミュージシャン向けの、高速でオフライン完結のサンプルライブラリブラウザです。フォルダをスキャンし、ファイル名から BPM/キー/楽器を抽出し、内容ハッシュで重複を検出し、波形プレビュー・MIDI ピアノロール・再生操作付きの検索可能なテーブルを提供します。

> English documentation: [README.md](README.md)

---

## 機能

### コア
- **高速フォルダスキャン** — WAV, MP3, FLAC, AIFF, M4A, OGG, WMA, AAC, MIDI を再帰的にスキャン
- **波形プレビュー** — ファイル全体の波形を 1200 ピークの要約として描画
- **再生エンジン** — Symphonia ベースのオーディオ + `rodio` シンク、MIDI は `rustysynth` で合成
- **SQLite データベース** — トラックメタデータ、お気に入り、並べ替え/フィルタ状態を永続化
- **あいまい検索** — 180 ms の入力デバウンス付き高速あいまい一致

### 音楽メタデータ（DTM 向け）
- **ファイル名解析** — 一般的なパック命名規則から BPM・キー・楽器を抽出（例: `120BPM Am Piano Loop.wav`）
- **お気に入り** — スター切り替えと永続化
- **重複検出** — FNV-1a コンテンツハッシュでライブラリ内の同一ファイルを特定
- **並べ替え・フィルタ** — BPM、キー、アーティスト、アルバム、お気に入りで絞り込み

### MIDI
- **ピアノロール描画** — MIDI トラックはトラック一覧にピアノロール波形を表示
- **ドラム / シンセチャンネルモード** — MIDI 再生ごとに GM 音色セットを選択
- **MIDI シーク** — プログレスバーで MIDI 再生内をシーク

### UI とユーザー体験
- **スキャン進捗** — 段階的進捗表示（スキャン中 → 解析中 → 保存中）、キャンセルボタン、完了サマリー
- **エラー表示** — ウォークエラーと失敗バッチをカウントしてステータスに表示
- **ツリー状態の永続化** — 展開フォルダと選択フォルダを再起動時に復元
- **パニックセーフ** — 実行パスから `panic`/`expect`/`unwrap` を排除

## ソースからのビルド

### 必要条件

| プラットフォーム | 必要なもの |
|----------|-------------|
| **Linux** | `pkg-config`, `libasound2-dev`, `libfontconfig1-dev`, `libglib2.0-dev`, `libgtk-3-dev` |
| **macOS** | Xcode Command Line Tools (`xcode-select --install`) |
| **Windows** | Visual Studio 2022（C++ ビルドツール） |

### ビルド

```bash
git clone https://github.com/kuwa72/sampleman.git
cd sampleman
cargo build --release
```

バイナリは `target/release/sampleman` に生成されます。

### テスト実行

```bash
bash test/run-tests.sh
```

純粋なロジックモジュール（音楽メタデータ解析、MIDI ユーティリティ）には `#[cfg(test)]` 単体テストが含まれます。GUI イベントハンドラとオーディオデバイスパスは自動テストの対象外です。

## 使用方法

1. **ライブラリフォルダを追加** — フォルダアイコンをクリックするか、ディレクトリをウインドウにドラッグします。
2. **スキャン待ち** — sampleman がオーディオファイルを再帰的にスキャンしてインデックスします。
3. **参照・検索** — 検索バー（あいまい一致）または任意の列での並べ替えを使用します。
4. **プレビュー** — トラックの再生ボタンをクリックして試聴。プログレスバーをドラッグしてシーク。
5. **整理** — お気に入り（スター）を切り替え、BPM/キー列でコレクションをフィルタリングします。

### キーボードショートカット

| キー | 操作 |
|-----|--------|
| <Space> | 選択トラックの再生 / 一時停止 |
| Delete / Fn+Delete | 5 秒前後にシーク |
| Up / Down | トラック一覧 / フォルダのナビゲート |
| Ctrl/Cmd + F | 検索にフォーカス |

## プロジェクト構造

```
sampleman/
├── src/               # コア Rust: UI 結合、オーディオ、データベース、スキャン、音楽メタデータ
├── src/midi_util.rs   # MIDI 解析、ピアノロール、GM 楽器テーブル
├── src/music_meta.rs  # ファイル名 BPM/キー/楽器パーサー
├── ui/main.slint      # Slint UI 定義
├── build.rs           # Slint UI コンパイル + Windows アイコン
├── icons/             # アプリアイコン（Windows ICO、macOS ICNS、各種サイズ）
├── test/
│   └── run-tests.sh   # テストランナー（CI + ローカル）
├── Cargo.toml         # パッケージマニフェスト
└── .github/workflows/ # CI + リリースワークフロー
```
